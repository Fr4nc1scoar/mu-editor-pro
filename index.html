📖 Instrucciones de Uso

                
            

            


                

                    
🎮 ¿Qué es MuEditor Pro?

                    
Editor visual para los archivos MonsterSetBase de tu servidor MU Online Season 6. Te permite agregar, editar y eliminar monstruos, NPCs y spots de cada mapa de forma cómoda.

                


                

                    
📂 Paso 1 — Importar un archivo

                    
    
                        
  1. Click en 📂 Importar
    2. 
                        
  2. Selecciona el archivo del mapa que quieres editar, por ejemplo: 000 - Lorencia.txt
    3. 
                        
  3. Los archivos están en la carpeta del servidor: MuServer\Data\MonsterSetBase\
    4. 
                        
  4. También puedes importar archivos vacíos (como Stadium) para crear spawns desde cero
    5. 
                    

                    
💡 El editor recuerda la ubicación del archivo original. Al guardar, se sobreescribe directamente.

                


                

                    
➕ Paso 2 — Agregar Spawns

                    
    
                        
  1. Click en ➕ Agregar Spawn
    2. 
                        
  2. Selecciona el tipo de spawn:
    3. 
                    

                    

                        

                            0
                            🛡️ NPC
                            Posición fija — Merchants, guards, trainers
                        

                        

                            1
                            👾 Spot
                            Área + Cantidad — Monstruos que respawnean en una zona
                        

                        

                            2
                            🐉 Monster
                            Posición fija — Monstruos individuales, bosses
                        

                    

                    
    
                        
  1. Busca el monstruo por nombre o ID, o navega la lista completa
    2. 
                        
  2. Selecciona el mapa, configura coordenadas y dirección
    3. 
                        
  3. Click 💾 Guardar Spawn
    4. 
                    

                


                

                    
✏️ Paso 3 — Editar o Eliminar

                    
    
                        
  • ✏️ Editar: Click en el lápiz de la fila, o doble-click en la fila
    • 
                        
  • 🗑️ Eliminar: Click en la papelera, o selecciona varios y click "Eliminar"
    • 
                        
  • 📋 Duplicar: Crea una copia del spawn seleccionado
    • 
                    

                


                

                    
💾 Paso 4 — Guardar

                    
    
                        
  • Si importaste un archivo: 💾 Guardar sobreescribe el archivo original directamente
    • 
                        
  • Si creaste desde cero: 💾 Descargar genera el archivo con el nombre del mapa
    • 
                        
  • El archivo se guarda con el formato correcto para tu servidor
    • 
                    

                    
💡 Usa Chrome o Edge para que el guardado directo funcione.

                


                

                    
🔍 Buscar y Filtrar

                    
    
                        
  • Buscar: Escribe nombre, ID o coordenadas en la barra de búsqueda
    • 
                        
  • Filtrar por sección: Ver solo NPCs, Spots o Monsters
    • 
                        
  • Filtrar por mapa: Ver solo un mapa específico
    • 
                        
  • Ordenar: Click en las cabeceras de columna (Sec, Mob ID, Nombre, etc.)
    • 
                    

                


                

                    
⌨️ Atajos de Teclado

                    

                        
Ctrl + NNuevo spawn

                        
Ctrl + OImportar archivo

                        
Ctrl + SGuardar / Exportar

                        
EscCerrar modal

                        
Doble clickEditar un spawn

                    

                


                

                    
📝 Vista Previa

                    
Click en 📝 Vista Previa para ver el archivo generado en formato texto, tal como lo leerá el servidor. Puedes copiar el contenido con el botón 📋.

                


                

                    
📁 Archivos del Servidor

                    
Los archivos MonsterSetBase se encuentran en:

                    MuServer\Data\MonsterSetBase\
                    
Cada archivo corresponde a un mapa. Ejemplo:

                    
    
                        
  • 000 - Lorencia.txt → Lorencia
    • 
                        
  • 001 - Dungeon.txt → Dungeon
    • 
                        
  • 006 - Stadium.txt → Stadium
    • 
                        
  • 030 - Castle Siege.txt → Castle Siege
    •
